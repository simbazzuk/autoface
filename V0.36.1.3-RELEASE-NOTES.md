# AutoFace v0.36.1.3 — Clear Mutual Messaging

Small overlay patch for v0.36.1.2 / v0.36.1.1.

## Changes
- Replaces confusing `MUTUAL BY DESIGN / No unsolicited messaging` wording.
- New headline: `Messaging starts when interest is mutual`.
- Explains clearly that both people must independently select `Interested`.
- Adds a simple four-stage visual:
  - You're interested
  - They're interested
  - It's mutual
  - Chat unlocks
- Changes the CTA to `View my introductions`.
- Keeps privacy reassurance about email, mobile number and private Atlas answers.
- No messaging, matching, membership, Firestore or compatibility logic changes.
