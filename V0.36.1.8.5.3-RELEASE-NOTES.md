# AutoFace v0.36.1.8.5.3 - Founder Counter Card

Improves the `18 of 20` Founder count area in the landing-page welcome modal.

## Changes
- Replaces the flat rectangular count with a more premium Founder availability card.
- Shows the remaining number inside a circular gold counter.
- Adds `of 20` directly inside the counter.
- Adds a clear `FOUNDER PLACES REMAINING` label.
- Adds a short explanation that places are allocated automatically to eligible verified members.
- Adds a subtle divider between the count and explanation.
- Keeps the existing popup, buttons, live Founder count, and membership logic unchanged.
- Adds a stacked mobile layout for narrow screens.
