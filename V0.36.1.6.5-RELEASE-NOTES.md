# AutoFace v0.36.1.6.5 - Blocked Profiles Compatibility Fix

Fixes a blocked member disappearing from Introductions but not appearing under Account & Notifications > Blocked profiles.

## Root cause
AutoFace has used two compatible Firestore block record shapes during development:
- `blockerUid` / `blockedUid`
- `fromUid` / `toUid`

The Blocked Profiles screen was only querying `blockerUid`, while block enforcement already supports the deterministic block document itself. A legacy-shaped block could therefore be active but absent from the management list.

## Fix
- `/api/blocks` now reads both block record shapes.
- Results are merged and de-duplicated by blocked user.
- Existing `generalLocation` is shown when available.
- Blocked profiles are sorted by block date.
- v0.36.1.6.4 unblock behaviour is preserved: unblocking removes the block but does not automatically restore the old introduction.
- No payment, message-limit, matching or safety-enforcement rules are weakened.
