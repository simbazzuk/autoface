# AutoFace v0.35.9.8 — Atlas Reflection Resilience & Diagnostics

- Adds safe server-side diagnostics for Atlas AI generation failures so Vercel logs show the failure stage, HTTP status, model and provider message.
- Never logs API keys, prompts, full Atlas answers or raw user data.
- Atlas Reflection first attempts schema-guided JSON generation.
- If the configured Gemini model/API rejects `responseJsonSchema`, AutoFace automatically retries with standard JSON output and validates/sanitises the response locally.
- Adds diagnostics for empty responses and JSON parse failures.
- Keeps the existing safe user-facing fallback if both Gemini paths fail.
- No deterministic compatibility or authenticity logic changes.
