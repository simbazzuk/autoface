# AutoFace v0.35.9.7 — Atlas Reflection Availability

- Fixes Atlas Reflection configuration detection.
- `ATLAS_AI_ENABLED` is parsed safely and case-insensitively.
- Supports either `GEMINI_API_KEY` or `GOOGLE_API_KEY`.
- `GEMINI_MODEL` defaults to `gemini-3.6-flash` if omitted.
- The Atlas status endpoint now returns a safe reason when Reflection is unavailable, without exposing secrets.
- Relationship Profile now distinguishes between the feature being switched off, the API key missing, the model missing, and the status endpoint being unreachable.
- No deterministic compatibility or authenticity logic changes.
