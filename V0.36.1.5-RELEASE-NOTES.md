# AutoFace v0.36.1.5 - Face Verification Success Readability

Visual patch for the successful AWS face-verification result.

- Replaces the low-contrast success box with a high-contrast green confirmation card.
- Increases the success icon, heading and explanatory text.
- Splits liveness confidence and face similarity into clear metric cards.
- Makes confidence percentages larger and easier to scan.
- Adds short explanations for each metric.
- Improves mobile stacking.
- No AWS Rekognition, verification threshold, identity, Firestore or email logic changes.
