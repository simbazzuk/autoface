# AutoFace v0.35.9.6 — Mandatory Profile Photo

- Makes a primary profile photo mandatory before a member profile can be saved.
- The profile page checks whether an active server-managed profile photo exists.
- Save Profile remains disabled until the photo is present.
- Adds clear `REQUIRED` / `PHOTO ADDED` status treatment to the photo card.
- Shows `Add a profile photo to continue` beside the disabled save action.
- Client-side save validation prevents accidental saves without a photo.
- Firestore rules also enforce the requirement so the browser UI cannot be bypassed.
- Existing profiles without a photo remain readable, but must add a photo before their next profile update/save.
- Removing a profile photo immediately disables profile saving again.
- Face Verification remains a separate trust step after the mandatory photo is added.
- Also updates Firestore relationship-profile rules to allow the v0.35.9.5 `consentForAiReflection` field.
