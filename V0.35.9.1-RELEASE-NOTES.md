# AutoFace v0.35.9.1 — Verification Email Wiring

- Connects successful AWS Rekognition face verification to the AutoFace notification service.
- Creates the existing in-app verification notification after a successful live face + profile-photo match.
- Passes the same verification event to the v0.35.9 email channel.
- With Resend unconfigured, a successful verification should create an `emailDeliveries` Firestore record with `status: configuration_required`.
- With Resend configured, the same event sends the privacy-safe verification email according to the user's email preference.
- Failed verification attempts do not generate a success email.
- Package version updated to 0.35.9.1.
