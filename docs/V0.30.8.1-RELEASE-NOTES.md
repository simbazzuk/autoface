# AutoFace v0.30.8.1 — Profile Permissions & Development Tools

## Fixes
- Firestore profile rules now allow and validate the profile fields introduced in recent releases: profession, education detail, Sikh identity/lifestyle fields and hobbies.
- Development Tools no longer depend on an `@autoface.test` email address in local development.
- Any authenticated account running the local development build can access the development harness.
- When a local account actually runs a development action, the server marks it as a test/development profile.
- Production continues to refuse Development Tools.

## Security
This patch does not make `demoProfiles` client-readable and does not loosen production Development Tools access.
Profile writes remain owner-only and field-whitelisted.
