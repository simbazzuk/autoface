# AutoFace v0.34.5 — Registration Experience

Refreshes Create Account to feel warmer, more premium and more consistent with the newer AutoFace visual language.

## Changes
- Adds a blue/purple glow behind the registration area.
- Gives the registration form a subtle blue/violet gradient and accent strip.
- Adds a clear `Create your profile` introduction inside the form.
- Improves field focus states with blue highlighting.
- Restyles Terms / Privacy as a trust-and-control panel.
- Strengthens the Create Account call-to-action with the AutoFace gradient.
- Reworks `What happens next` into a connected five-step visual journey.
- Gives `Your control` a blue/cyan treatment with clear privacy-control signals.

No registration, Firebase Authentication, beta-invite, email-verification or data logic changes.
