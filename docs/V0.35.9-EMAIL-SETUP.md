# AutoFace v0.35.9 — Email setup

1. Create a Resend account and verify a sending domain.
2. Add the required DNS records for the sending domain.
3. Create a Resend API key.
4. In Vercel, add `RESEND_API_KEY`.
5. Set `AUTOFACE_EMAIL_FROM` to a verified sender, for example `AutoFace <notifications@mip.chat>`.
6. Set `AUTOFACE_APP_URL=https://mip.chat`.
7. Redeploy.
8. In AutoFace Account settings, enable the email categories you want to test.
9. Create a mutual introduction or complete verification and confirm an `emailDeliveries` Firestore record has status `sent`.

The application does not expose the Resend key to the browser. Emails contain only generic notification text and direct the user back to authenticated AutoFace for profile/compatibility detail.
