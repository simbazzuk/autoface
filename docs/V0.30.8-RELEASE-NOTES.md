# AutoFace v0.30.8 — Atlas Profile Intelligence

Atlas recommendation details now use the richer member characteristics as a separate deterministic context layer.

## New profile alignment indicators
- Lifestyle
- Career & education
- Sikh lifestyle
- Shared interests
- Location fit

## Characteristics considered
Where explicitly supplied, Atlas Profile Intelligence can use profession area, career importance, education, Sikh practice, diet, appearance, hobbies, height preference and location preference.

## Important boundary
- The official relationship compatibility percentage is unchanged.
- Profile alignment indicators are contextual 1–5 signals, not compatibility scores.
- They use deterministic rules rather than Gemini.
- Caste is displayed elsewhere only when supplied and is deliberately excluded from Atlas Profile Intelligence.
- No traits are inferred.
- Optional Gemini semantic insight remains a separate dual-opt-in layer.
