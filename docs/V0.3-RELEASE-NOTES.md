# AutoFace v0.3 release notes

- Adds a provider-neutral identity verification journey.
- Adds Firebase Admin token verification for trusted server-side verification writes.
- Adds server-controlled verification sessions and security-event audit records.
- Adds a development-only external-provider simulator.
- Enables identity (+30) and liveness (+20) authenticity signals when server evidence exists.
- Keeps photo verification reserved for a later release.
- Tightens Firestore rules so clients cannot write identity verification, authenticity, verification-session or security-event records.
- Continues Zero-ID Storage: AutoFace has no passport, driving-licence, raw selfie, liveness-video or biometric-template upload fields.
