# AutoFace v0.33.5 — Discovery Test Reset & Development Tools Readability

## Reset reviewed profiles
Development Tools now includes a dedicated `Reset reviewed profiles` action.

It clears the current test account's non-mutual Discovery decisions:
- Interested
- Saved for later
- Not for me

It deliberately preserves:
- Mutual introductions
- The member Profile
- Atlas relationship answers
- Introduction Preferences
- Authenticity / identity signals
- Profile photo
- Seeded synthetic community

The same reset action is also available from the empty Discover state during local development.

## Readability
Development Tools typography and spacing have been increased across:
- Card descriptions
- Reset / seed rows
- Discovery readiness checks
- Buttons
- Supporting notes

No Firestore security-rule changes or new collections are required.
