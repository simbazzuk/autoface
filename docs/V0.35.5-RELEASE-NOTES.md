# AutoFace v0.35.5 — Colour & Visual Depth

This release responds to early user feedback that the product could feel too dark while preserving AutoFace's premium dark identity.

## What changed

- Introduces a richer global page background using restrained blue, violet, pink and cyan ambient gradients.
- Adds subtle visual depth to navigation, cards, forms, page heroes and the footer.
- Gives long pages alternating low-intensity colour washes so sections are easier to visually separate.
- Reworks previously flat dark homepage sections so they remain consistent with the new colourful atmosphere.
- Adds understated colour accents to common cards without turning the interface into a light theme.
- Retains the existing dark cards and high-contrast text for readability.
- Includes a simplified mobile treatment and respects reduced-motion preferences.

## Behaviour

This is a visual-only release. Authentication, Atlas, discovery, introductions, AWS face verification, biometric consent and verified-photo integrity logic are unchanged from v0.35.4.1.
