# AutoFace v0.31.0 — My Introductions

Turns the existing mutual-match foundation into a clearer member journey.

## My Introductions
- New three-state experience: Introductions, Waiting, Saved.
- Waiting shows outgoing private interest that is not yet mutual.
- Saved shows profiles deliberately held for later.
- Mutual introductions show a five-stage connection journey:
  Introduced → Talking → Getting to know → Met → Connection progressing.
- Existing private Connection spaces remain the destination for mutual introductions.
- Summary counters make the member's current state immediately visible.
- Clear empty states explain what happens next.

## Product language
Reinforces the AutoFace model:
`Interested is not a match. Mutual interest creates an introduction.`

## API
`GET /api/introductions` now returns waiting, mutual, saved and counts while preserving the legacy `introductions` field.
Adds an authenticated mutual-introduction stage endpoint for future Connection-stage controls.

No Firestore security-rule deployment is required for this release because introduction writes continue through authenticated server routes.
