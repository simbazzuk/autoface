# AutoFace v0.4.0

## Added
- Private AutoFace relationship profile.
- Profile completeness score separate from Authenticity Score.
- Privacy/disclosure controls.
- Private profile preview.
- Firestore profile schema validation and owner-only access.
- `My Profile` navigation entry.

## Security/privacy posture
- Existing v0.3 identity/liveness evidence remains server-controlled.
- No identity documents or biometric media are added.
- Profiles are not readable by other users in this release.
