# AutoFace v0.6 — Explainable Compatibility Engine

## Purpose
v0.6 proves that AutoFace can compare two consented relationship profiles using a deterministic, explainable scoring model before any member discovery or matching is enabled.

## Privacy boundary
- The signed-in user's `relationshipProfiles/{uid}` document is read using existing owner-only Firestore rules.
- v0.6 does not read any other member's relationship profile.
- Three synthetic demonstration profiles are bundled in application code solely to exercise the engine.
- Compatibility results are calculated in memory and are not written to Firestore.
- Free-text answers are not scored.

## Dimensions and weights
| Dimension | Weight |
|---|---:|
| Family outlook | 18% |
| Communication style | 14% |
| Social rhythm | 10% |
| Career priority | 10% |
| Lifestyle rhythm | 14% |
| Relocation flexibility | 10% |
| Shared interests | 8% |
| Personal independence | 8% |
| Relationship pace | 8% |

For 1–5 scale dimensions, identical answers score 100. Each one-point difference reduces the dimension score by 20 points. Relationship pace uses 100 for an exact match, 70 for an adjacent preference and 40 for the largest difference.

## Guardrails
The compatibility score is not a prediction of relationship success and should not be presented as one. Lower-scoring dimensions are labelled as conversation points rather than reasons to reject a person. The engine is deterministic and no LLM decides the score in v0.6.
