# AutoFace v0.32.0 — Guided Onboarding & Readiness

Transforms Getting Started into a guided member journey.

## New readiness journey
- Six clear setup steps: Profile, Photo, Atlas, Preferences, Authenticity, Discovery.
- Overall setup percentage and visual progress ring.
- Next Best Action guidance.
- Profile completeness, Atlas completeness and authenticity snapshots.
- Clear explanation that completing setup does not automatically make a profile discoverable.
- Preview of what happens after setup: Discover → private choice → mutual introduction.
- Preferred name is used in the onboarding greeting when supplied.
- Active mutual introductions are surfaced in the readiness experience.

## Navigation
`Getting Started` is renamed to `My Journey`.

## Data
Uses existing profile, relationship profile, Discovery preferences, profile photo, identity and matches data. No new Firestore collections or security-rule changes are required.
