# AutoFace v0.30 — Sikh Community Direction

## Positioning
AutoFace is now presented as a modern way for Sikhs to meet through considered, AI-assisted introductions rather than traditional introduction routes.

## Landing page
- Sikh-community-first hero proposition while retaining the existing AutoFace visual identity.
- New global community network section and stylised world map.
- Initial network points: UK, Europe, Canada, Australia and Kenya.
- Explicit wording that the map represents the intended community network, not claimed current membership.

## Profile
- Adds optional `caste` / community self-description to the member profile.
- Caste is never inferred by AutoFace.
- Members can leave the field blank.
- v0.30 records the profile attribute only; it is not silently added to Atlas compatibility scoring.

## Architecture
No new Firestore collection is required. The optional field is stored on the existing `profiles/{uid}` document.
