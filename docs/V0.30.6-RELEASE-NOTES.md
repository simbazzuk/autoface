# AutoFace v0.30.6 — Engaging Discover Profile Traits

## Discover card experience
- Makes the About Me area a prominent colour-highlighted statement.
- Adds a new At a Glance icon strip for profile characteristics.
- Shows visual indicators for education, profession, Sikh appearance, diet and Sikh practice when supplied.
- Keeps textual labels under every icon so meaning never depends on the icon alone.
- Retains detailed profession/education cards and community/career-fit pills beneath the visual summary.

## Behaviour
This is a presentation patch only. It does not change:
- compatibility scoring
- Discovery eligibility
- career preference behaviour
- Atlas AI
- Firebase data model
