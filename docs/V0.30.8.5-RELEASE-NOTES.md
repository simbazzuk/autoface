# AutoFace v0.30.8.5 — Homepage User Journey Flow

Replaces the older three-stage homepage journey with a clearer six-stage visual flow:

1. Create profile
2. Atlas relationship understanding
3. Discover considered profiles
4. Express private interest
5. Mutual interest creates an introduction
6. Messaging opens after the introduction

The mutual-interest stage visually shows two independent choices converging into one introduction.

No Firebase, Discovery, messaging, recommendation, or Atlas logic changes.
