# AutoFace v0.30.3 — Development Reset & Sikh Test Data

## Development Tools
Adds `/development-tools`, visible only to local-development test profiles.

### Reset my test journey
Preserves Firebase Authentication and the test-profile marker while clearing:
- profile and Sikh identity/lifestyle fields
- Atlas relationship profile
- Discovery preferences
- reviewed recommendation decisions
- mutual introductions/conversations
- notifications, blocks and test activity
- profile photo

A synthetic trust baseline is retained so the rebuilt test profile can enter Discovery after setup.

### Seed Sikh test community
Creates or refreshes 8 clearly synthetic `@autoface.test` profiles across Manchester, London, Birmingham, Leeds, Leicester, Toronto, Nairobi and Melbourne. Profiles vary in Sikh practice, diet, caste/community, appearance and relationship answers so compatibility behaviour can be tested.

## Safety boundary
- API refuses to run when `NODE_ENV=production`.
- Only test-profile users can invoke it.
- Synthetic accounts are marked `isTestProfile` and `developmentSeed`.
- No real member account is targeted by seed actions.
