# v0.5 Relationship Profile design

The v0.5 relationship profile creates structured compatibility evidence before AutoFace introduces matching. It deliberately separates authenticity (identity evidence), basic profile completeness (descriptive profile fields), and relationship-profile completeness (compatibility-oriented answers).

The structured dimensions are family outlook, communication directness, social energy, career priority, routine/adventure preference, relocation flexibility, importance of shared interests, and independence preference. They are not scored as good or bad. Future compatibility logic can compare or complement these dimensions explicitly.

The Atlas panel is deterministic in v0.5. It summarises the user's selected dimensions using transparent rules and does not ask a generative model to decide who a user should date or marry. This keeps early behaviour testable and explainable while providing a seam for richer Atlas explanations in a later release.
