Improves readability across the My Journey / Get Started experience.

- Larger text in the simplified three-part journey.
- Improved readability in right-hand readiness cards and beta feedback.
- Responsive sizing retained for mobile.

No onboarding logic, Firebase, Discovery, Atlas, recommendation or security behaviour changes.
