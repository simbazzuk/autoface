# AutoFace v0.30.8.3 — Profile Identity & Test Readiness

## Member identity
- Adds required surname to the private profile record.
- Adds optional preferred name.
- Preferred name is used publicly when supplied; otherwise first name is used.
- Surname is never included in the safe Discovery projection.
- Firestore rules validate the new fields.

## Development test readiness
- Adds a Discovery Readiness panel to Development Tools.
- Shows Profile, visibility, Atlas Profile, compatibility consent and authenticity readiness.
- Adds `Make my test account Discovery-ready`.
- The helper sets profile visibility, compatibility consent when an Atlas Profile exists, and a development trust baseline.
- It does not invent Atlas relationship answers.

## Seed data
Synthetic Sikh profiles now include private surnames and hobby selections.
