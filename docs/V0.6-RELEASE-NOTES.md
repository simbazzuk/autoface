# AutoFace v0.6 Release Notes

- Added `/compatibility` Compatibility Lab.
- Added deterministic weighted compatibility engine.
- Added dimension-level explanations, strongest alignments and conversation points.
- Added three synthetic profiles for safe development testing.
- No public discovery, member-to-member profile access or matching is enabled.
- Compatibility results are not persisted.
- Free-text relationship answers remain private and are not scored.
- Existing authenticity, profile and relationship-profile models are unchanged.
