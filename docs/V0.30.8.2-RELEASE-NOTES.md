# AutoFace v0.30.8.2 — Firestore Profile Enum Fix

Corrects two Firestore rule values that did not match the profile UI/model:

- Adds `practising` to the allowed Sikh practice values.
- Replaces legacy education values with the current `school_college` value.

These mismatches could cause an otherwise valid Profile save to return
`Missing or insufficient permissions`.

The profile save error now also gives a clearer reminder when the latest
Firestore rules have not been deployed.
