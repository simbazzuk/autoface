# AutoFace v0.33.1 — Phone verification reCAPTCHA fix

- Fixes `reCAPTCHA has already been rendered in this element` when retrying mobile verification.
- Disposes the previous Firebase `RecaptchaVerifier` before every new SMS attempt.
- Empties the reCAPTCHA host before a new verifier is created and after failed attempts.
- Cleans up the verifier when the Authenticity Centre unmounts.
- Trims the submitted phone number.
- Corrects the mobile verification success message typo.

No Firestore rules or data migration is required.
