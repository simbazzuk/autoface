# v0.7.1 Release Notes

AutoFace v0.7.1 introduces a development test harness for repeatable Discovery testing.

Highlights:

- `npm run seed:demo` command.
- Three reusable test members with 75% authenticity.
- Completed profile and Atlas compatibility data.
- Discovery enabled automatically for demo members.
- TEST PROFILE badge shown in Discovery and Introductions.
- Existing demo interests/matches reset on every seed.
- `npm run seed:demo:clean` removes seeded accounts and data.
- Seeder refuses production-looking Firebase projects and production runtime environments.
- No change to real-member privacy boundaries or the compatibility model.
