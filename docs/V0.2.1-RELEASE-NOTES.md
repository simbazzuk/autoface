# AutoFace v0.2.1 — Authenticity Centre polish

This release preserves the v0.2 security model and improves the user experience around verification evidence.

## Changes

- Updated authenticity levels:
  - 0: Not Yet Established
  - 1–24: Basic
  - 25–49: Confirmed
  - 50–79: Verified
  - 80–100: Highly Verified
- Replaced the heading "Your identity confidence" with "Build your authenticity" to avoid overstating what basic account verification proves.
- Added progress information showing completed verification signals and remaining score.
- Added a recommended next verification step.
- Added expandable explanations for every authenticity signal.
- Added clearer distinction between available checks and planned v0.3 capabilities.
- Improved phone-verification messaging and retry handling.
- Improved small-screen layout and button sizing.
- Retained the Zero-ID Storage principle and no identity-document upload capability.

## Security model unchanged

Authenticity remains deterministic. Atlas or any LLM does not calculate authenticity. v0.2.1 does not add passport, driving-licence, selfie, biometric-template or identity-document storage.
