# AutoFace v0.34.0 — Deterministic Test Environment

Introduces a reliable clean-reset and seed-validation workflow for local development.

## Factory reset test environment
A new destructive local-development action:
- preserves the currently signed-in Firebase Authentication account
- clears that account's AutoFace application journey
- removes all 8 deterministic synthetic users from Firebase Authentication
- removes their Profile, Atlas, identity, preferences and photo metadata
- removes interests, matches, blocks, conversations, notifications and other user-scoped journey data

The operation requires a confirmation dialog plus typing:
`RESET TEST ENVIRONMENT`

It remains blocked when `NODE_ENV=production`.

## Seed + validate community
Seeding now validates every deterministic member after creation.

Each synthetic profile is checked for:
- Firebase Authentication user
- Profile
- Atlas relationship profile
- future-introduction visibility
- compatibility consent
- development authenticity baseline
- test-profile marker
- Discovery preferences

Development Tools displays an 8-profile health report and identifies any missing requirement.

## Recommended test workflow
Factory reset → Create Profile → Atlas → Introduction Preferences → enable Discovery → Seed + validate community → Discover.

No Firestore rule changes or new persistent collections are required.
