# AutoFace v0.35.9 — Email Notifications & Communication Preferences

## What changed
- Adds a server-side transactional email notification channel alongside the existing in-app Activity centre.
- Adds separate email preferences for mutual introductions, unread-message alerts, Connection updates and verification updates.
- Safety/account-protection email remains mandatory.
- Mutual-introduction and verification emails default on unless explicitly disabled.
- Message and Connection email alerts are opt-in.
- Message email is throttled to one email per recipient/conversation every 30 minutes.
- Email content is deliberately privacy-safe and excludes profile photos, compatibility details and sensitive profile/Atlas information.
- Delivery attempts are recorded in `emailDeliveries`; message throttle state is recorded in `emailNotificationState`.
- Uses the Resend HTTPS API without adding a package dependency.
- Email provider failure never blocks the underlying introduction/message/verification action.

## Environment
Set:
- `RESEND_API_KEY`
- `AUTOFACE_EMAIL_FROM` (a verified sender/domain)
- `AUTOFACE_APP_URL=https://mip.chat`

If `RESEND_API_KEY` is absent, email delivery is skipped and logged with `configuration_required`.
