# AutoFace v0.35.4 — Verified Photo Integrity

## What changed

- The primary profile photo now has a SHA-256 integrity fingerprint and version.
- Successful AWS face verification is bound to the exact primary photo that was compared.
- Replacing a verified primary photo automatically resets Face Verified, Photo Verified and Liveness Verified when the new image differs from the verified image.
- Removing the primary photo also resets face-verification status.
- Verification sessions record the profile-photo fingerprint/version used when the liveness session starts.
- The result endpoint refuses to complete verification if the primary photo changes while a verification session is in progress.
- Re-uploading the exact same image does not invalidate an existing verified-photo binding.
- The profile page clearly tells the member when a photo change requires re-verification.

## Why

A Face Verified signal must remain linked to the exact profile image that was checked. Without this control, a member could verify one photograph and later replace it with an unrelated image while retaining the badge.
