# AutoFace v0.4 — Profile Foundation

v0.4 introduces the first AutoFace relationship profile while preserving the security boundary established in v0.3.

## Scope

- Owner-only Firestore profile document at `profiles/{uid}`.
- First name, age, broad location, optional height, occupation and education.
- Relationship intention and a short `About me` introduction.
- Privacy controls for age, broad location and occupation.
- Profile visibility state prepared for future matched introductions.
- Deterministic profile-completeness score kept separate from Authenticity.
- Private preview of how the profile may eventually be presented.

## Deliberately not included

v0.4 does not provide discovery, matching, messaging, Atlas relationship analysis, public profiles or profile-photo upload.

It also deliberately does not collect home address, passport/licence details, religion/caste, salary, employer address or biometric files.

## Data boundary

Profile documents are readable and writable only by the authenticated owner. Firestore rules validate the supported schema and field lengths. Cross-user profile reads will require a separate permissions design in a later release.
