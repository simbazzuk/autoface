# AutoFace v0.35.2 — AWS camera compatibility check

## What changed

- Builds on v0.35.1 camera diagnostics.
- Requests an AWS-suitable camera mode before starting Face Liveness: 640x480 minimum, 1280x720 preferred, and at least 15 fps.
- Reports the actual negotiated camera resolution and frame rate.
- Marks cameras that open successfully but cannot meet the AWS Face Liveness minimum as incompatible rather than displaying a misleading “Camera ready” message.
- Releases the diagnostic camera stream and waits briefly before AWS Amplify opens the webcam for the liveness session.
- Does not change Firebase authentication, profile data, matching, Atlas, or verification thresholds.

## Test

1. Open `/verify-face`.
2. Select **Test camera**.
3. Confirm the result shows an AWS-compatible resolution (for example 640x480 or higher) and at least 15 fps.
4. Select **Verify my face**.
5. If the pre-flight passes but Amplify still reports that the camera is inaccessible, capture the browser console output so the next patch can focus on the Amplify/React integration rather than Windows camera permissions.
