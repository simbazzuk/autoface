# AutoFace v0.33.0 — Guided Profile-to-Discovery Journey

## UX goal
Early user testing showed that members could complete a Profile without understanding that Atlas and introduction preferences must come before meaningful Discovery.

## Changes
- Adds a shared four-step journey bar across Profile, Atlas Profile, Introduction Preferences and Discover.
- Successful Profile save now presents a clear `Continue to Atlas` completion state.
- Successful Atlas save presents `Set my preferences`.
- Successful preference save presents `Start discovering`.
- Discover now shows a readiness checklist and routes the member directly to the next incomplete step instead of only showing a generic locked state.
- My Journey adds a simplified three-part explanation:
  About you → What matters to you → Meet people.
- `Discovery Preferences` is renamed in navigation/UI to `Introduction Preferences` for clearer language.

## Architecture
The underlying technical readiness controls remain in place. The member-facing flow is simplified without weakening compatibility consent, visibility or authenticity eligibility.

No new Firestore collections or rule changes are required.
