# AutoFace v0.30.1 — Sikh Identity & Lifestyle Profile

Adds an optional Sikh-specific profile section.

- Appearance: Turbaned / Clean shaven or non-turbaned / Not applicable / Prefer not to say
- Sikh practice: Amritdhari / Practising / Moderate / Cultural or not religious / Prefer not to say
- Diet: Vegetarian / Non-vegetarian / Vegan / Prefer not to say
- Caste/community remains optional free text

All fields are self-described. AutoFace does not infer them and v0.30.1 does not automatically use them to change compatibility scoring. They are stored on the existing profiles document, so no new Firestore collection is required.
