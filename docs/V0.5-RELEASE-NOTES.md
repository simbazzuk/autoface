# AutoFace v0.5 — Atlas Relationship Profile

v0.5 adds the first compatibility-focused profile while keeping matching disabled.

## Added
- Private `/relationship-profile` experience.
- Eight structured compatibility dimensions (1–5 scales).
- Relationship pace plus three free-text reflection questions.
- Explicit consent before answers may be used for future compatibility recommendations.
- Deterministic, explainable Atlas relationship insight derived from the user's own answers.
- Independent relationship-profile completeness score.
- Owner-only `relationshipProfiles/{uid}` Firestore model and security rules.

## Privacy boundary
- No discovery or matching in v0.5.
- Relationship-profile documents are owner-readable only.
- No exact address, salary, identity-document data, medical data or biometric files are collected by this feature.
- Atlas insight in v0.5 is deterministic and does not use an LLM to decide matches.
