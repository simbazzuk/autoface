# AutoFace v0.36.1.8.2.2 - Header Encoding Repair

Repairs the mojibake characters that appeared in the header after the v0.36.1.8.2.1 menu patch.

## Root cause
Windows PowerShell read a BOM-less UTF-8 `Header.tsx` using the local Windows text encoding before writing it back as UTF-8. Unicode chevrons such as `⌄` were therefore converted into visible mojibake such as `âŒ„`.

## Fix
- Restores the My AutoFace dropdown chevron.
- Restores the Safety & Privacy dropdown chevron.
- Uses HTML numeric entity `&#8964;` in JSX so future Windows PowerShell rewrites cannot corrupt the symbol.
- Uses Node.js for the actual source-file rewrite, preserving UTF-8.
- Does not change any navigation links, membership logic, or menu behaviour.
