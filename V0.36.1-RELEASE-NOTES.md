# AutoFace v0.36.1 — Founding Member Entitlements

- Adds server-owned membership records using `memberships/{uid}` with `free`, `founding` and future `plus` plans.
- Free users keep the core AutoFace journey: profile, photo, verification, Atlas profile, core deterministic compatibility, three considered Discovery profiles, mutual introductions, messaging and safety.
- Founding Members unlock:
  - Atlas Reflection
  - full Atlas AI explanation endpoints
  - advanced introduction preferences
  - full recommendation history
  - expanded Discovery (up to 8 considered profiles)
  - Founding Member recognition
- Premium features remain visible to Free users with a clear Founding Member lock and pricing CTA instead of disappearing.
- Adds `/api/membership` for safe authenticated entitlement reads.
- Adds server-side entitlement checks so UI changes cannot grant premium access.
- Adds Admin membership controls to grant Founding membership or return a user to Free while Stripe is not yet connected.
- Admin membership changes are written to `adminAuditEvents`.
- Adds membership status to Account & Notifications.
- Membership Firestore documents are explicitly blocked from direct client reads/writes.
- Reconciles the homepage Founding Member proposition with the current first-500 pricing plan.
- Payment processing is still intentionally not included.
