# AutoFace v0.36.1 Test

## Deploy
1. Run `npm run build`.
2. Deploy `firestore.rules`.
3. Deploy the application to Vercel.

## Free user
1. Sign in as Priya (or another test account).
2. In Admin, set the account to Free.
3. Open Account & Notifications and confirm `AutoFace Free`.
4. Open Atlas Profile and confirm Atlas Reflection is visible but locked.
5. Open Introduction Preferences and confirm age, broad location and relationship intent remain available while advanced preferences are locked.
6. Open Recommendation History and confirm only the 3 most recent items are available.
7. Open Discovery and confirm the curated limit is 3.

## Founding Member
1. In Admin, choose `Grant Founding` for Maya (or another test account).
2. Sign in as that member.
3. Confirm Account & Notifications shows Founding Member and a founding number.
4. Confirm Atlas Reflection can be generated.
5. Confirm advanced introduction preferences can be saved.
6. Confirm full recommendation history is available.
7. Confirm Discovery can return up to 8 considered profiles.

## Security
1. Confirm a client cannot write `memberships/{uid}` directly in Firestore.
2. Confirm calling Atlas Reflection as a Free user returns `MEMBERSHIP_REQUIRED`.
3. Confirm Admin membership changes appear in `adminAuditEvents`.
