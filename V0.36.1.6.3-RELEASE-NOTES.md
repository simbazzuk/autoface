# AutoFace v0.36.1.6.3 - Introduction Chat State

UI and server-read-model patch for the Free chat entitlement.

- Mutual introductions remain visible after the Free message allowance is exhausted.
- The Introduction card changes to `Conversation paused`.
- Shows `Free message allowance used`.
- Shows the sender's message count, e.g. `5/5 free messages sent`.
- Reassures the member that the existing conversation remains readable.
- Changes the locked-card CTA to `View conversation`.
- Free users who still have allowance see their remaining message count.
- Founding/Plus members do not see the Free allowance banner.
- No matching, payment, block/report, verification or message-limit rules are changed.
