# AutoFace v0.36.1.7.1 - Membership Route Correction

Corrective patch for the partially applied v0.36.1.7 Founding Programme release.

## What happened
The v0.36.1.7 installer successfully added the Pricing Founding Programme panel, but its installer expected a two-line membership read pattern that no longer matched the current membership API.

## Fix
The current membership route is now updated directly to:
1. authenticate the user,
2. call `ensureFoundingMembership(user.uid)`,
3. then return the latest result from `membershipFor(user.uid)`.

The Founding allocation therefore occurs automatically when an eligible Free member's membership is read.

The patch is safe to apply after the partially applied v0.36.1.7 installer.
