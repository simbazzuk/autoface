# AutoFace v0.35.9.2 — Authenticity Centre Production Cleanup

- Removes the simulated Identity + Liveness option from the user-facing Authenticity Centre.
- Removes MFA/passkey from the user-facing authenticity checklist while it is not implemented.
- Replaces the old Face Verification "coming soon" card with the live AWS Face Verification capability.
- Rebalances the authenticity score so only genuine current capabilities contribute:
  - Email verification: 20
  - Mobile verification: 25
  - Face verification: 55
- Legacy identity/MFA/liveness fields remain in the data model for backwards compatibility but carry zero score and are not shown as verification achievements.
- Face Verification is treated as one combined trust signal: AWS Face Liveness + one-to-one comparison with the current profile photo.
- Updates privacy and support wording so AutoFace does not imply a government-ID check is currently performed.
- No compatibility or Atlas ranking logic changes.
