# AutoFace v0.36.1.4 - Entitlement Test Harness

Small development-only overlay patch.

## What it adds
- New Free vs Founding Member panel under Development Tools.
- Switch the currently signed-in local test account between Free and Founding.
- One-click entitlement test-data creation.
- Creates one mutual synthetic introduction so Introductions and Messaging can be tested.
- Creates five reviewed recommendation records so Free history (3) can be compared with Founding history (all 5).
- Provides direct links to Introductions, History, Discover and Atlas Profile.
- Reset action removes only entitlement-harness records and returns the account to Free.

## Expanded Discovery test
After testing history, use the existing Reset reviewed profiles control. The non-mutual reviewed decisions are cleared while the synthetic mutual introduction is preserved. This makes the remaining seeded profiles available again:
- Free is capped at 3 Discover candidates.
- Founding can see the larger available set (up to the configured Founding limit).

## Safety
- The endpoint refuses to run in production mode.
- It only operates on synthetic seeded test profiles and the signed-in local development account.
- It does not change production matching behaviour or Stripe/payment behaviour.
